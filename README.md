# Prato Para Todos

Projeto acadêmico desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas**, com foco em sustentabilidade, inclusão e desenvolvimento web.

## Sobre o projeto

O **Prato Para Todos** propõe uma plataforma para aproximar alimentos disponíveis de organizações capazes de transformar excedentes em refeições, ajudando a reduzir desperdício e facilitar conexões entre doadores e iniciativas sociais.

## Estrutura planejada

A experiência é organizada em páginas para:

- apresentação do projeto;
- mural de oportunidades/resgates;
- oferta de alimentos;
- informações sobre a iniciativa;
- guia de utilização;
- contato.

## Tecnologias estudadas no projeto

- HTML
- CSS
- JavaScript
- Git e GitHub
- integração de dados via API/fetch
- Supabase como evolução da camada de dados

## Objetivos acadêmicos

O projeto é utilizado para praticar:

- estruturação semântica de páginas;
- estilização responsiva;
- manipulação do DOM;
- eventos e lógica em JavaScript;
- consumo de APIs;
- versionamento com Git;
- colaboração por GitHub;
- organização de interface a partir do protótipo criado no Figma.
