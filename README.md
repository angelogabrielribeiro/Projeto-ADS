# Projeto ADS

Repositório acadêmico para estudos, exercícios e projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas**.

## Objetivo

Registrar a evolução prática em desenvolvimento de software, mantendo exercícios e pequenos projetos organizados para consulta e acompanhamento do aprendizado.

## Tecnologias de estudo

- HTML
- CSS
- JavaScript
- Python
- Git e GitHub

## Organização

Este repositório será usado para reunir atividades acadêmicas e exercícios que façam sentido manter versionados. Projetos maiores e independentes permanecem em repositórios próprios.

## Status

📚 **Em evolução contínua durante a graduação.**
